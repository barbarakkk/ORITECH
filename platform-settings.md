# Platform Settings

## Platform Settings

![Deposits and withdrawals settings](.gitbook/assets/general-deposits-withdrawals.png)

Use Platform Settings for global controls that affect the entire platform.

[Open the complete Platform Settings manual](documentation.md#10-platform-settings)

### General

Configure withdrawal thresholds and weekly or monthly limits. These settings apply independently.

Configure chat access through wager requirements, email verification, and the master chat toggle. Set the Bonus Wheel reload time in hours.

### Countries

Manage country availability, restrictions, and default language. **Is Active** controls registration availability. **Is Restricted** blocks all platform access.

Review both flags together. They control different access states.

### Languages

Manage the catalog of languages available across the player site and admin panel. Activating a language makes it available for content selection.

Translations remain managed in each content record. Deactivating a language does not remove existing translations.

Review dependent policies before changing withdrawal, country, or language settings.
