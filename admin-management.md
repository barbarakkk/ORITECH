# Admin Management

## Admin Management

![Admin Users list](.gitbook/assets/admin-users-list.png)

Use this module to manage staff access and permission boundaries.

[Open the complete Admin Management manual](documentation.md#11-admin-management)

### Admin Users

Create, edit, disable, and assign roles to staff accounts. Monitor last-login activity and two-factor authentication.

Disable an account to remove access without deleting its history. Disabling 2FA only removes the second login factor.

### Roles and Permissions

Create roles and grant permissions through the module and action tree. Search for permissions, then save the completed role.

Role changes affect every assigned administrator immediately. Apply least privilege and create narrow roles for specialized work.
